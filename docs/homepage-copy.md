# Product Narrative

Most prompt security tools answer:

"What vulnerabilities exist?"

PromptSonar answers:

"Where can this prompt actually go?"

The difference matters.

A prompt only becomes dangerous when it reaches memory, tools, MCP servers, shell execution, filesystem access, network actions, or other privileged sinks.

PromptSonar traces those paths before they reach production.
