# PromptSonar Positioning

Category:
AI Execution Path Analyzer

Not:
- Prompt scanner
- AI firewall
- Prompt injection detector

Core idea:
See where your prompt goes.

PromptSonar traces prompts through:
- Memory
- Tools
- MCP Servers
- Agent Routers
- Privileged Actions

Security findings are an output.

Execution visibility is the product.
