# PromptSonar v1.1.0 Release Notes Draft

Release theme: local-first MCP config security.

## Headline

PromptSonar v1.1.0 adds `audit-mcp`, a local scanner for Claude, Cursor, and repository MCP configuration files.

## Why This Matters

MCP configs are becoming an agent supply-chain input. A copied config can define remote endpoints, local commands, filesystem scope, environment variables, credentials, and tool descriptions that are exposed to an AI agent. PromptSonar gives developers and security teams a deterministic local review step before trusting those configs.

## New Command

```bash
npx @promptsonar/cli audit-mcp
```

Audit a specific config:

```bash
npx @promptsonar/cli audit-mcp ./mcp.json
```

Machine-readable output:

```bash
npx @promptsonar/cli audit-mcp --json --output promptsonar-mcp.json
npx @promptsonar/cli audit-mcp --sarif --output promptsonar-mcp.sarif
```

## Rule Coverage

| Rule | Severity | Description |
|---|---|---|
| `MCP-001` | Critical | Unencrypted, local, or raw-IP MCP endpoint. |
| `MCP-002` | High | Over-broad filesystem, shell, admin, or network scope. |
| `MCP-003` | High | Remote MCP server missing authentication indicators. |
| `MCP-004` | Medium | Prompt-injection or suspicious directive text in tool descriptions/config. |
| `MCP-005` | High | Hardcoded secrets in args, env, headers, URLs, or config text. |
| `MCP-006` | Medium | Unknown remote domain requiring review. |
| `MCP-007` | Low | Legacy, malformed, or unauditable config shape. |

- `./claude_desktop_config.json`
- `./.cursor/mcp.json`

## Known Limits

- This is deterministic static analysis, not runtime sandboxing.
- Unknown domains are review prompts, not definitive maliciousness.
- Auth detection looks for indicators; teams still need to validate actual auth behavior.
- The benchmark is a launch-grade synthetic fixture suite, not a large real-world corpus yet.
