# Evidence Archive

Store durable EB-1A-supporting evidence here. URLs can disappear, so each important public proof point should have a local copy.

## Naming Convention

Use date-prefixed filenames:

```text
YYYY-MM-DD_source_short-description.png
YYYY-MM-DD_source_short-description.pdf
YYYY-MM-DD_metrics_snapshot.json
```

Examples:

```text
2026-06-01_github_stars.png
2026-06-01_npm_downloads.png
2026-06-01_vscode_installs.png
2026-06-15_hackernews_showhn.png
```

## What To Save

- GitHub stars, forks, contributors, releases, issues, and pull requests.
- npm weekly downloads and package version.
- VS Code Marketplace installs, reviews, and ratings.
- External articles, newsletters, podcasts, conference pages, and social posts.
- Enterprise testimonials or permissioned usage evidence.
- arXiv preprint page and PDF once submitted.

Do not commit private customer data, secrets, or immigration attorney work product.
